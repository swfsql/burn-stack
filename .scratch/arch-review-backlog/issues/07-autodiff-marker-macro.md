## Agent brief

**Category:** enhancement

**Summary:** Delete `decl_autodiff_backend_ext!`. After the burn-mamba ticket, no code
calls it.

**Current behaviour:**

- The module `utils::backend_macros` exports two macros:
  - `impl_backend_ext_for_burn_backends!` emits an impl with the default body of an
    extension trait for each plain backend.
  - `decl_autodiff_backend_ext!` declares a marker trait for `Autodiff<B>`, with a
    blanket impl. Its doc gives the reason: a caller can bound its own generics on the
    marker.
- The blocks of burn-mamba have no backend parameter, so no caller can use that bound.
- The docs of `utils::backend_macros` and of its `mod` line in `utils` name the
  "autodiff marker trait".

**Desired behaviour:**

- `decl_autodiff_backend_ext!` is gone.
- `impl_backend_ext_for_burn_backends!` does not change.
- The header of `utils::backend_macros` and the doc of its `mod` line describe only
  `impl_backend_ext_for_burn_backends!`.
- No doc of burn-stack names the deleted macro or the marker trait.

**Acceptance criteria:**

- [ ] The burn-mamba ticket is `resolved`. In the working tree of `../burn-mamba`,
      `rg 'decl_autodiff_backend_ext'` over `src`, `examples` and `benches` finds
      nothing.
- [ ] In this repo, `rg -i 'decl_autodiff_backend_ext|autodiff marker|marker trait'`
      outside `.scratch/` finds nothing.
- [ ] The checks and tests of this repo pass, as `CLAUDE.md` gives them, with no
      warnings.

**Out of scope:**

- `impl_backend_ext_for_burn_backends!` and the backend list: ticket 01.
- The burn-stack pin of burn-mamba. burn-mamba does not call the macro, so a later pin
  move does not depend on this ticket.
